# AGENTS.md

## Project overview

This is a tiny Python command-line project for testing OpenAI Codex with a GitHub repository.

## Development rules

- Keep changes small and readable.
- Update README.md when behavior changes.
- Add or update tests for non-trivial changes.

## Commands

Run the app:

```bash
python -m src.main --name Codex
```

Run tests after installing pytest:

```bash
python -m pytest
```
