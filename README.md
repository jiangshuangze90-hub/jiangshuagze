# jiangshuagze

A tiny Python project initialized for OpenAI Codex.

## What it does

This project provides a simple command-line greeting app.

## Run locally

```bash
python -m src.main --name Codex
```

Expected output:

```text
Hello, Codex!
```

## Install test dependencies

```bash
python -m pip install -r requirements-dev.txt
```

## Run tests

```bash
python -m pytest
```

## Use with Codex

From the repository directory, run:

```bash
codex
```

Then ask Codex to read the project, make a small change, run tests, and summarize the diff.
